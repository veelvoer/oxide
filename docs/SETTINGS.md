# Settings

`Super+,` or `oxide-settings`. Search at the top finds a page by name or topic. Changes apply instantly (switch
*Apply instantly* off to review and **Save** yourself). **Advanced** shows more options on every page and three
extra pages.

| Page | What it does |
|---|---|
| **Wi-Fi** | switch Wi-Fi, scan, connect (asks for the password), disconnect; details of the connection in Advanced |
| **Bluetooth** | switch, scan, pair, connect and disconnect devices |
| **Sound** | output and input devices, volume, mute, microphone |
| **Displays** | brightness; each connected screen: resolution, refresh rate, scale, position (drag to arrange in Advanced); settings are kept for screens that are unplugged |
| **Power** | battery, power profile |
| **Theme** | mode, roundness, palette (incl. *From wallpaper*), accent, background, apps that follow the theme |
| **Windows** | gaps, borders (gradient colors), rounding, opacity, blur, shadows |
| **Animations** | feel presets; per-animation curves, speeds and styles in Advanced |
| **Bar** | drag modules between left/center/right, position, style, height, spacing, pills, opacity (hidden when you use your own shell) |
| **Launcher** | calculator, history, web search engine, results shown (hidden with your own shell) |
| **Assistant** | name, API key, model, permissions |
| **Layout** | dwindle or master, focus follows mouse, scroll to switch workspaces |
| **Input** | keyboard layout and repeat, touchpad, mouse |
| **Shortcuts** | search, click one to rebind (press the keys), add, duplicate, delete |
| **Terminal** | the standard kitty: font, size, opacity, padding, cursor, history |
| **Config** | where the file is, reload, import from Hyprland, reset everything |
| *Shells* (Advanced) | install, import, switch and remove shells ([SHELLS.md](SHELLS.md)) |
| *Apps* (Advanced) | commands to start with Oxide, window rules, environment variables |
| *Own configs* (Advanced) | use your own shell/kitty/fish/GTK files; edit any of them in the built-in editor with syntax colors; import files |

The sidebar footer shows whether Oxide is running. Everything here is also in `oxide.toml`
([CONFIG.md](CONFIG.md)).
