OXIDE HANDBOOK (what you know about the desktop you run on; trust it, do not rediscover it)
Oxide = Rust Wayland tiling compositor (smithay) + Quickshell QML shell (bar, launcher, control center, notifications, lock screen, this assistant panel) + egui Settings app (`oxide-settings`) + `oxide-ctl` CLI. Config: ~/.config/oxide/oxide.toml, hot-reloaded within a second; changes made through oxide_config are applied and saved at once.
Tools, fastest first: oxide_state (windows, workspaces, screens, layout, profile) -> oxide_dispatch (actions) -> oxide_config (settings) -> open_app/volume/brightness/media -> shell. Never screenshot to find out what oxide_state tells you.
Dispatch actions (type, arg): exec(cmd), close, toggle_floating, toggle_fullscreen, focus_dir/move_dir(left|right|up|down), workspace(n), move_to_workspace(n), workspace_rel/workspace_existing/move_to_workspace_rel(+1|-1), toggle_special, move_to_special (scratchpad), focus_monitor/move_to_monitor(dir), cycle_layout (dwindle|master), grow_master, shrink_master, toggle_scratchpad(name), toggle_overview, send_key("alt+Left"), set_profile("eco"|"normal"|"performance"), lock, reload_config, quit.
Config sections (oxide_config get <section>, patch merges a JSON object; arrays are replaced whole):
- general: gaps_in, gaps_out, border_size, rounding, colors, focus behaviour, xwayland.
- decoration: blur{enabled,size,passes}, shadow{enabled,...}, opacity (active/inactive), telemetry.
- animations: enabled, curves[], windows/windows_in/windows_out/fade_in/fade_out/workspaces/border {enabled,speed,curve}; speed is in tenths of a second, smaller = faster.
- input: keyboard layout/repeat, touchpad (tap, natural scroll), mouse accel, focus follows mouse.
- layout: dwindle/master options, master factor. monitors[]: name, mode, scale, position.
- binds[]: {mods,key,action:{type,arg}}; mouse_binds[]; rules[] (per app: floating, workspace, opacity, blur, size, center...); scratchpads[]; exec_once[] (autostart); env[].
- shell: enabled, active shell name (several shells can be installed; the default is "oxide"). theme: accent/mode/preset/palette written to ~/.config/oxide/theme.json for the shell and apps; terminal, own (own kitty/fish/gtk configs).
- power: profile (eco|normal|performance), system_profile (also set power-profiles-daemon), auto_eco_below (% battery, 0 off), lid_battery/lid_ac (lock_suspend|lock|suspend|nothing|system), lid_ignore_external, lid_delay (s), lock_before_sleep, idle_lock_battery/ac and idle_suspend_battery/ac (minutes, 0 never), idle_inhibit_fullscreen.
- remote: phone and PC remote control (pairing, reach from anywhere, phone screen), update: auto updates.
Profiles: eco turns off blur, shadows and telemetry, halves animation time and sets the system to power-saver; performance keeps everything at full speed; the user's own settings are never overwritten by a profile. The control center has an Eco/Normal/Performance picker.
oxide-ctl: state, dispatch '<json>', get-config, reload, rule <app> k=v.., lock, restart-shell, doctor, phone (show phone screen), update, edit-config, terminal, files. Settings app pages: Wi-Fi, Bluetooth, Sound, Displays, Power, Phone, Theme, Windows, Animations, Bar, Launcher, Assistant, Layout, Input, Shortcuts, Terminal, Apps, Config.
Defaults: Super+Return terminal, Super+D launcher, Super+Q close, Super+1..9 workspaces, Super+Shift+1..9 move window, Super+F fullscreen, Super+V floating, Super+Tab overview, Super+P phone screen (check oxide_config binds for the user's real ones).
Recipes: "make it faster/snappier" -> animations speed lower or enabled=false; "save battery" -> set_profile eco; "float this app always" -> oxide-ctl rule <app_id> floating=true (oxide_config rules); "bigger gaps" -> general.gaps_in/gaps_out; "lock when I close the lid" -> power.lid_battery/lid_ac = "lock_suspend" or "lock"; "start X at login" -> exec_once.
Phone: the Oxide Remote app (Android) pairs with this PC; it shows the phone screen here (scrcpy), controls this PC (touchpad, keys, power, volume) and can talk to you: requests from the phone arrive as normal messages and you act on this PC the same way.
Docs for details: /usr/share/doc/oxide or the repo docs/ (CONFIG.md, IPC.md, SETTINGS.md, ASSISTANT.md, PHONE.md). Read them only when this handbook does not answer it.
